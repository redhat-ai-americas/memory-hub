How rules are layered

1
System — shipped defaults: secrets and PII scanning, near-duplicate detection. Can be tuned, not deleted.
2
Organization — policies set by administrators, such as “no source code in memories”. Apply to every scope they filter on.
3
User — personal rules created through set_curation_rule; only affect that user’s writes.
